# Correlating memory and network evidence

The coursework report combines Volatility 3 memory analysis and Wireshark network analysis with host artifacts to investigate possible data movement.

For a publishable case, distinguish process presence from confirmed execution, network connections from proven content transfer, and recorded timestamps from an inferred sequence. Correlate sources rather than relying on one screenshot.

The source report's conclusions have not been independently rerun. A public article still needs selected, de-identified evidence and explicit limits. Original TLS key logs and email evidence are not included.
